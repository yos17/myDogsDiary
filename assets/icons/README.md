# Extension Icons

To complete the extension setup, you need to add PNG icon files in these sizes:
- icon16.png (16x16 pixels)
- icon32.png (32x32 pixels)
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

## Design Suggestions

The icons should feature:
- 🎯 Target/bullseye symbol (representing focus)
- Purple gradient background (#667eea to #764ba2)
- Clean, modern, minimal design
- Good contrast for visibility

## Quick Icon Creation

You can create these icons using:
1. **Online Tools**: Canva, Figma, Photoshop
2. **Icon Generators**: realfavicongenerator.net
3. **AI Tools**: DALL-E, Midjourney with prompt: "App icon for productivity extension, target symbol, purple gradient, minimal, modern"

## Temporary Solution

For testing, you can use the emoji as a temporary icon:
1. Create a simple square with the 🎯 emoji
2. Export in the required sizes
3. Replace later with professional icons

The extension will still work without custom icons (Chrome will use defaults), but custom icons provide better user experience.
